# 注文履歴CSVエクスポーター（Amazon.co.jp対応・非公式）

Amazon.co.jp の注文履歴を **商品ごと** にCSVで保存する Chrome 拡張機能です。
注文履歴の画面では省略される商品名や、1注文に複数商品があるときの商品ごとの価格も、CSVで一覧にできます。

> Amazon.com, Inc. およびその関連会社とは関係のない、非公式のツールです。

## 出力される項目

| 列 | 内容 |
| --- | --- |
| 注文日 / 注文番号 | 注文ごとの情報 |
| 商品名 / 単価 / 数量 / 金額 | 商品ごとの情報（金額＝単価×数量） |
| 商品の小計 / 配送料 / 注文合計 | 注文全体の金額 |
| ご請求額 | ギフト券・ポイント・割引を差し引いた、実際にカードに請求される金額 |
| 割引等 | 割引・ポイント・ギフト券の内訳 |
| URL | 注文詳細ページ |

CSVは BOM 付き UTF-8 なので、Excel でそのまま開けます。

## インストール

**Chromeウェブストアから**：ストアのページで「Chromeに追加」を押します。

**このリポジトリから**

1. 「Code」→「Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします
3. 「パッケージ化されていない拡張機能を読み込む」で `extension` フォルダを選びます

## 使い方

1. Amazon.co.jp にログインし、Amazonのページを開きます
2. ツールバーの拡張機能アイコンを押し、年と月の範囲を選びます（初期値は先月〜今月）
3. 「CSVを保存」を押すと、画面右下に進捗が出て、終わるとCSVがダウンロードされます

1注文あたり約1秒かかります（Amazonに負荷をかけないよう間隔を空けています）。処理中にタブを閉じると中断されます。

## よくある質問

- **「Amazon.co.jp のタブで実行してください」と出る**：注文履歴ページが自動で開くので、もう一度ボタンを押してください。
- **「ログインが必要です」と出る**：Amazon にログインしてから再実行してください。
- **0件になる**：選んだ期間に注文がないか、Amazon のページ構成が変わった可能性があります。後者の場合は Issues で教えてください。
- **商品名が「(商品情報を取得できませんでした)」になる**：Kindle などデジタル注文は詳細ページの形式が違うため、一覧の情報だけを出しています。

## プライバシー

- 読み取ったデータはブラウザ内で CSV にするだけで、外部には一切送信しません。
- 権限は `activeTab` と `scripting` のみ。アイコンを押したタブの中でだけ動きます。
- 詳しくは [プライバシーポリシー](docs/privacy.html) をご覧ください。
